# 🧠 Quizly – A Simple Web-Based Quiz App

Quizly is a lightweight, responsive quiz application built with HTML, CSS, and JavaScript. It allows users to test their knowledge across various categories like HTML, CSS, JavaScript, Science, Geography, and Math. At the end of the quiz, users can view their score and restart the quiz.

## 🚀 Features

- ✅ Multiple-choice questions (MCQs)
- ✅ Covers multiple topics (HTML, CSS, JS, Science, Geography, Math)
- ✅ Shows score at the end
- ✅ Restart quiz button with creative design
- ✅ Interactive and mobile-responsive UI
- ✅ Gradient background and modern button effects
